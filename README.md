# 周复盘独立看板

## 1. 项目目的

该项目用于承载周复盘看板的独立版本。

目标不是继续在旧平台单文件上叠改，而是单独维护一个更稳定、更易迭代的周复盘页面，用于后续持续优化视觉、口径和复盘表达。

## 2. 当前范围

首版包含以下模块：

- 核心指标
- 本周关键判断
- 生命周期趋势
- 渠道效率与内容表现
- 站外曝光
- 品牌声量

顶部保留了 Tab 预留位，但当前只启用“周复盘总览”。

## 3. 当前口径

### 3.1 内容池

- 最近 30 天发布的帖子

### 3.2 环比

- 当前自然周产生的数据 vs 上一自然周产生的数据

### 3.3 发布时间批次

- 第 1 周：最近 1-7 天发布
- 第 2 周：最近 8-14 天发布
- 第 3 周：最近 15-21 天发布
- 第 4 周：最近 22-30 天发布

### 3.4 互动

- 总互动 = 平台累计互动差值
- 当前实现基于 `likes + comments + shares + saves` 的累计差值近似得到

## 4. 目录说明

- `index.html`：页面入口
- `styles.css`：页面样式
- `app.js`：页面渲染与计算逻辑
- `review-mock-data.js`：从旧周复盘页面抽离出的 mock 数据
- `COLLAB.md`：项目协作约定
- `TASKS.md`：任务板

## 5. 运行方式

直接打开以下文件即可：

- `output/weekly-review-dashboard/index.html`

当前实现不依赖构建工具，也不依赖旧主页面。
